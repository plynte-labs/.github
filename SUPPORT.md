# Support

## Where to ask

- Use GitHub Issues for bugs, feature requests, and documentation gaps.
- Use pull requests for concrete improvements.
- For security issues, use the private process in [SECURITY.md](SECURITY.md).

## Before opening an issue

- Search existing issues first.
- Include your environment, reproduction steps, expected behavior, and actual behavior.
- Keep one problem per issue.
